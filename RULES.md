# Правила проекта LeetCode75

## Структура папок и файлов
- Папка: `{Category}/{Difficulty}/_XXX_Name/`
- Categories: `ArrayAndString`, `TwoPointers`, `SlidingWindow`, `PrefixSum`, `HashMapSet`, `Stack`, `Queue`, `LinkedList`, `BinaryTree`, `BinarySearchTree`, `Graphs`, `HeapPriorityQueue`, `BinarySearch`, `Backtracking`, `DP`, `BitManipulation`, `Trie`, `Intervals`, `MonotonicStack`
- Difficulties: `Easy`, `Medium`
- Паттерн: `_` + номер задачи + `_` + название (CamelCase)
- Файл: `{номер}_{название}.cs`
- Namespace: `LeetCodeTests.{Category}.{Difficulty}._{number}_{Name}`

## Класс Solution
- Должен точно повторять сигнатуру с сайта LeetCode
- Возвращает `default` значение для компиляции до реализации
